# Upload the review

The only website file you need is `index.html` at the workspace root (about 547 KB, UI v2).

Its pictures, lesson data, CSS and JavaScript are embedded. You do not need to upload `assets`, `data`, `scripts`, `qa`, `tmp`, the source PDF or the skill folders to run the website.

Place `index.html` at the root of the folder your GitHub Pages site publishes. Keep the filename exactly `index.html`. Open the resulting site on the learner's device and test a word's speaker button; browser voices depend on that device.

The same file can be opened locally before upload. Notes are saved per browser/origin: notes entered in a local file do not automatically transfer to the hosted website. Use For grown-ups → Download my notes to export them.

This workspace has no Git repository or configured remote. No GitHub commit, push or Pages deployment has been performed.
