# QA Rubric — Grade 4 ESL Learning Project

Score each dimension 0–2.

## 1. Big Question & purpose
- 0: child cannot tell what the unit is about
- 1: topic is visible but fragmented
- 2: Big Question drives the full lesson

## 2. Concept map
- 0: decorative / category boxes only
- 1: some relationships exist
- 2: concepts + labeled relationships + recall mode

## 3. Vocabulary
- 0: flat list
- 1: some clustering/visuals
- 2: concept-based clustering + useful visuals + pronunciation support

## 4. Thinking
- 0: recall-only questions
- 1: one reasoning task
- 2: explicit thinking routine + evidence/reasoning

## 5. Grammar
- 0: formula only
- 1: examples but weak context
- 2: grammar used as a tool to express unit meaning

## 6. ESL accessibility
- 0: text-heavy / adult language
- 1: partly simplified
- 2: concise child-facing English + scaffolded frames

## 7. Output
- 0: MCQ only
- 1: one productive task
- 2: multiple child-choice output modes

## 8. Recall
- 0: passive review
- 1: quiz only
- 2: retrieval through map/image/oral recall

## 9. Visual design
- 0: dense / inconsistent
- 1: usable
- 2: child-friendly, uncluttered, visuals support meaning

## 10. Source fidelity
- 0: unsupported content mixed in
- 1: mostly faithful
- 2: clear CORE vs EXTENSION provenance

### Shipping rule
- Minimum overall score: 16/20
- Mind map, ESL accessibility, and source fidelity must each score 2.
