# OD4 ESL Learning Designer Skill

Portable skill package for designing Oxford Discover Grade 4 learning projects for a 9-year-old ESL learner.

## Files
- `SKILL.md` — main skill instructions
- `rubrics/qa_rubric.md` — quality gate
- `templates/unit_blueprint.yaml` — unit planning schema
- `templates/vocabulary_card.schema.md` — vocabulary data structure
- `prompts/run_unit.md` — quick prompt for one unit
- `prompts/update_existing_project.md` — quick prompt for updating an existing HTML project

## Typical use
1. Put the skill folder in your skills/project instructions location.
2. Attach Oxford source files and your current HTML/project.
3. Use one of the prompts in `/prompts`.
4. Ask the agent to build and QA the downloadable artifact.

## Core principle
**Question → Explore → Connect → Think → Express → Remember**
